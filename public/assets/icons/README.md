# Ícone de agradecimento

`thank-you.svg` é uma reconstrução vetorial local do envelope “THANK YOU” visível no export `Frontend Challenge/Desktop/Confirmação de Pedido.png`. Não é um asset original baixado do Figma. A consulta do contexto da confirmação segue bloqueada pelo limite Starter; o SVG isolado original continua pendente.

Contorno cobre, envelope aberto e cartão reproduzidos como SVG; texto usa fonte de sistema Arial. Nenhum screenshot foi cortado/utilizado na UI, nenhuma das quatro artes Figma foi alterada. Esta aproximação está identificada em docs/visual-refinement.md para futura substituição pelo original quando recuperável.

Favicon em ../../favicon.svg: vetor simples da letra K nas cores da marca, criado para identificar a aba; não substitui o wordmark nem um export do Figma.
